<p class="wp-block-paragraph">O <strong>FlyOOBE</strong> (disponível no GitHub pelo desenvolvedor &#8220;builtbybel&#8221;) é uma ferramenta avançada projetada para facilitar a instalação, configuração e otimização do <strong>Windows 11</strong>.<sup></sup></p>



<p class="wp-block-paragraph">Ele é considerado a &#8220;evolução natural&#8221; do <strong>Flyby11</strong>, um projeto anterior do mesmo desenvolvedor que ficou famoso por permitir a instalação do Windows 11 em computadores que tecnicamente não atendem aos requisitos de hardware da Microsoft (como falta de TPM 2.0, Secure Boot ou processadores não suportados).<sup></sup></p>

<p class="wp-block-paragraph">Aqui estão os pontos principais sobre o que o FlyOOBE faz:</p>



<ul class="wp-block-list">
<li><strong>Instalação em hardware sem suporte:</strong>Ele utiliza métodos conhecidos (como a variante de configuração do Windows Server) para contornar as verificações de hardware durante o processo de instalação do Windows 11, permitindo que você instale o sistema em máquinas &#8220;incompatíveis&#8221;.</li>



<li><strong>Kit de ferramentas completo (Upgrade + OOBE):</strong>Enquanto o Flyby11 clássico focava apenas no processo de upgrade, o FlyOOBE oferece um conjunto mais amplo de recursos.Além de instalar o Windows, ele permite personalizar a <strong>OOBE</strong> (<em>Out-of-Box Experience</em> — a experiência inicial de configuração do Windows).</li>



<li><strong>Debloat e Otimização:</strong>A ferramenta inclui recursos para remover &#8220;lixo&#8221; do sistema (<em>debloat</em>), desativar componentes indesejados (incluindo recursos de IA, com ferramentas como o <em>Slopilot</em>) e aplicar ajustes que dão ao usuário maior controle sobre o sistema, em vez de seguir as configurações padrão da Microsoft.</li>



<li><strong>Foco na escolha do usuário:</strong> O objetivo principal do projeto é garantir que o PC funcione para o usuário, permitindo remover elementos que o sistema tenta forçar, como sugestões de IA ou outros aplicativos não essenciais.</li>
</ul>



<p class="wp-block-paragraph"><strong>Resumo da diferença:</strong></p>



<ul class="wp-block-list">
<li>Se você quer apenas <strong>instalar o Windows 11</strong> em um PC antigo, o FlyOOBE faz isso automaticamente.</li>



<li>Se você quer <strong>configurar e limpar o sistema</strong> após a instalação, o FlyOOBE oferece um ambiente centralizado para gerenciar extensões, remover aplicativos desnecessários e personalizar a experiência de uso.</li>
</ul>



<p class="wp-block-paragraph"><em>Nota: Por ser uma ferramenta que modifica o comportamento padrão da instalação do Windows e remove componentes do sistema, ela é voltada para usuários avançados ou entusiastas que desejam maior controle sobre seu sistema operacional.</em><sup></sup></p>
