<p class="wp-block-paragraph">Esse comando é um &#8220;truque&#8221; muito conhecido para quem está instalando o Windows 11.</p>



<p class="wp-block-paragraph">O comando <code>OOBE\BYPASSNRO</code> serve para <strong>ignorar a exigência de conexão com a internet e de uma Conta Microsoft</strong> durante a configuração inicial do computador.</p>



<h3 class="wp-block-heading">O que acontece quando você o usa:</h3>



<p class="wp-block-paragraph">Normalmente, o Windows 11 &#8220;força&#8221; você a se conectar ao Wi-Fi e entrar com uma conta da Microsoft (Outlook/Hotmail) para finalizar a instalação. Se você não tem internet no momento ou prefere usar uma <strong>Conta Local</strong> (apenas um nome de usuário, sem e-mail), esse comando libera essa opção.</p>



<h3 class="wp-block-heading">Como ele funciona na prática:</h3>



<ol start="1" class="wp-block-list">
<li><strong>OOBE</strong> significa <em>Out-of-Box Experience</em> (aquelas telas azuis de boas-vindas).</li>



<li><strong>Bypass NRO</strong> significa <em>Bypass Network Requirement Options</em> (Ignorar Opções de Requisito de Rede).</li>



<li>Ao digitar isso no Prompt de Comando (Shift + F10), o computador reinicia.</li>



<li>Quando ele volta, surge a opção mágica: <strong>&#8220;Eu não tenho internet&#8221;</strong>, permitindo que você crie um usuário offline.</li>
</ol>



<hr class="wp-block-separator has-alpha-channel-opacity" />



<h3 class="wp-block-heading">Quando usar?</h3>



<ul class="wp-block-list">
<li>Se o seu computador novo não reconheceu o driver de Wi-Fi e você está &#8220;preso&#8221; na tela de rede.</li>



<li>Se você não quer vincular seu Windows a uma conta de e-mail por questões de privacidade.</li>



<li>Se você está formatando o PC para outra pessoa e quer que ela mesma configure a conta depois.</li>
</ul>



<p class="wp-block-paragraph"><strong>Atenção:</strong> Após o comando, o sistema irá reiniciar automaticamente para aplicar a mudança. Não se assuste, é o comportamento padrão!</p>
