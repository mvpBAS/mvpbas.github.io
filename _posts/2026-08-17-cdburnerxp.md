<p class="wp-block-paragraph">O <strong>CDBurnerXP</strong> (acessível pelo site oficial <a target="_blank" rel="noopener" href="https://cdburnerxp.com/">cdburnerxp.com</a></p>



<p class="wp-block-paragraph">) é um programa gratuito e muito popular para o sistema operacional Windows, destinado à <strong>gravação de mídias ópticas</strong> (CDs, DVDs, Blu-rays e HD-DVDs) [1.1.1, 1.1.8].</p>



<p class="wp-block-paragraph">Aqui estão os detalhes principais sobre o que ele oferece:</p>



<h3 class="wp-block-heading">O que o programa faz?</h3>



<ul class="wp-block-list">
<li><strong>Gravação de dados:</strong> Permite gravar arquivos e pastas em discos [1.1.3, 1.1.7].</li>



<li><strong>Gravação de áudio:</strong> Cria CDs de áudio a partir de diversos formatos, como MP3, WAV, FLAC, Ogg Vorbis, entre outros [1.1.1].</li>



<li><strong>Manipulação de imagens ISO:</strong> Pode criar arquivos ISO (imagens de disco) e também gravar imagens ISO existentes em discos físicos [1.1.1, 1.1.4].</li>



<li><strong>Discos de inicialização (Boot):</strong> Possui suporte para a criação de discos de boot (geralmente para instalação de sistemas ou ferramentas de recuperação) [1.1.1, 1.1.4].</li>



<li><strong>Verificação:</strong> Oferece a opção de verificar os dados gravados logo após o processo para garantir que não houve erros durante a &#8220;queima&#8221; [1.1.1, 1.1.4].</li>
</ul>



<h3 class="wp-block-heading">Características principais<sup></sup></h3>



<ul class="wp-block-list">
<li><strong>Gratuito:</strong> É um <em>freeware</em>, o que significa que não há custo para uso pessoal ou profissional [1.1.2, 1.1.8].</li>



<li><strong>Fácil de usar:</strong> É conhecido por ter uma interface intuitiva, lembrando um gerenciador de arquivos (estilo Windows Explorer), onde você pode simplesmente arrastar e soltar os itens que deseja gravar [1.1.3, 1.1.6, 1.1.7].</li>



<li><strong>Compatibilidade:</strong> Funciona na maioria das versões do Windows (desde o Windows 2000 até as versões mais recentes, como o Windows 10/11) [1.1.2, 1.1.4].</li>



<li><strong>Multilíngue:</strong> Disponível em cerca de 40 idiomas, incluindo o português [1.1.1, 1.1.4].</li>
</ul>



<p class="wp-block-paragraph"><strong>Observação importante:</strong> Embora o programa seja gratuito, ele é de <strong>código fechado</strong> (<em>proprietary</em>), pois utiliza algumas bibliotecas que não são abertas [1.1.1, 1.1.4]. É sempre recomendado baixá-lo pelo site oficial ou por fontes confiáveis para garantir que você está instalando a versão legítima e livre de softwares indesejados [1.1.3, 1.1.8].</p>
