<p class="wp-block-paragraph">The main goal of this project is to create an intuitive GUI for the most common CLI package managers for Windows 10 and 11, such as&nbsp;<a href="https://learn.microsoft.com/en-us/windows/package-manager/">WinGet</a>,&nbsp;<a href="https://scoop.sh/">Scoop</a>,&nbsp;<a href="https://chocolatey.org/">Chocolatey</a>,&nbsp;<a href="https://pypi.org/">Pip</a>,&nbsp;<a href="https://www.npmjs.com/">Npm</a>,&nbsp;<a href="https://learn.microsoft.com/en-us/dotnet/core/tools/dotnet-tool-install">.NET Tool</a>,&nbsp;<a href="https://www.powershellgallery.com/">PowerShell Gallery</a>&nbsp;and more (Check out the package manager compatibility table)!. With this app, you can easily download, install, update, and uninstall any software published on the supported package managers — and much more!</p>
