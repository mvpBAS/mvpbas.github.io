<p class="wp-block-paragraph">O <strong><code>ytDownloader</code></strong> (desenvolvido pelo usuário <em>aandrew-me</em> no GitHub) é um aplicativo de computador (desktop) gratuito e de código aberto projetado para <strong>baixar vídeos e áudios da internet</strong>.</p>



<p class="wp-block-paragraph">Embora o nome sugira que ele serve apenas para o YouTube, ele funciona como uma interface gráfica (GUI) moderna para ferramentas poderosas de linha de comando (como o <code>yt-dlp</code>), permitindo baixar mídias de <strong>centenas de sites diferentes</strong>, incluindo YouTube, Facebook, Instagram, TikTok, Twitch, Twitter (X), entre outros.</p>



<p class="wp-block-paragraph">Aqui estão os principais recursos do projeto:</p>



<h3 class="wp-block-heading">Principais Funcionalidades</h3>



<ul class="wp-block-list">
<li><strong>Interface Moderna e Limpa:</strong> Ao contrário das ferramentas tradicionais por linha de comando, ele oferece uma interface visual simples onde você apenas cola o link do vídeo.</li>



<li><strong>Múltiplos Formatos e Resoluções:</strong> Permite escolher baixar apenas o áudio (em formatos como MP3, M4A, WAV) ou o vídeo completo em várias resoluções (incluindo qualidades altas como 1080p, 2K ou 4K, dependendo da disponibilidade da fonte).</li>



<li><strong>Download de Playlists:</strong> É possível colar o link de uma playlist inteira e baixar todos os vídeos de uma vez.</li>



<li><strong>Seleção de Trechos (Range Selection):</strong> Permite configurar um tempo de início e fim para baixar apenas um pedaço específico de um vídeo longo.</li>



<li><strong>Compressor de Vídeo Integrado:</strong> Possui uma ferramenta para reduzir o tamanho do arquivo do vídeo baixado utilizando aceleração por hardware (placa de vídeo).</li>



<li><strong>Download de Legendas:</strong> Permite baixar tanto legendas criadas manualmente quanto as geradas automaticamente pelas plataformas.</li>



<li><strong>Sem Anúncios ou Rastreadores:</strong> Por ser um projeto open-source mantido pela comunidade, o aplicativo é totalmente limpo, livre de anúncios falsos de download (comuns em sites dessa categoria) e de rastreadores de dados.</li>



<li><strong>Suporte a Vários Idiomas:</strong> A interface já possui tradução integrada para o Português do Brasil.</li>
</ul>



<h3 class="wp-block-heading">Tecnologias Utilizadas</h3>



<p class="wp-block-paragraph">O software é construído combinando tecnologias web e ferramentas robustas de manipulação de mídia de código aberto:</p>



<ul class="wp-block-list">
<li><strong>Electron e Node.js:</strong> Para criar o aplicativo desktop multiplataforma.</li>



<li><strong>yt-dlp:</strong> O &#8220;motor&#8221; por trás do app que lida com a raspagem e download dos vídeos dos sites.</li>



<li><strong>FFmpeg:</strong> Ferramenta utilizada nos bastidores para juntar os fluxos de áudio e vídeo de alta definição ou para realizar a compressão de arquivos.</li>
</ul>



<h3 class="wp-block-heading">Compatibilidade</h3>



<p class="wp-block-paragraph">O aplicativo é multiplataforma e está disponível para:</p>



<ul class="wp-block-list">
<li><strong>Windows</strong> (via instalador executável <code>.exe</code>, <code>.msi</code>, ou gerenciadores de pacotes como Winget e Chocolatey).</li>



<li><strong>Linux</strong> (em formatos universais como Flatpak, AppImage e Snap).</li>



<li><strong>macOS</strong> (via arquivo <code>.dmg</code>).</li>
</ul>
